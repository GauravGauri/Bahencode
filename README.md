# behencode ♡<br>> **"Where she is free to be all of her."**<br><br>`behencode` is a modern, high-aesthetic e-commerce platform for premium apparel, designed with a focus on fluid user experiences, beautiful visual design, and robust performance. This workspace contains both the Next.js frontend application and the Node.js/Express backend API.<br><br>---<br><br>## 📂 Project Architecture<br><br>The project is structured as a monorepo consisting of the following key directories and components:<br><br>```<br>Bahencode/<br>├── frontend/             # Next.js 16 (App Router, Tailwind CSS v4, Framer Motion)<br>├── backend/              # Node.js & Express API (MongoDB, JWT Auth, Mongoose)<br>├── behencode.html        # Interactive static HTML/CSS layout & prototype design<br>└── README.md             # This documentation file<br>```<br><br>---<br><br>## 🛠️ Technology Stack<br><br>### Frontend (`/frontend`)<br>*   **Framework:** Next.js 16 (App Router, TypeScript)<br>*   **Styling & Motion:** Tailwind CSS v4, PostCSS, Framer Motion, GSAP, Lenis Smooth Scroll<br>*   **3D Elements:** Three.js, React Three Fiber (`@react-three/fiber`), `@react-three/drei`<br>*   **Authentication:** NextAuth.js<br>*   **State & Fetching:** Axios, React Hook Form, Zod (Validation), Swiper<br><br>### Backend (`/backend`)<br>*   **Runtime & Framework:** Node.js, Express.js<br>*   **Database:** MongoDB via Mongoose<br>*   **Security:** Helmet, Express Rate Limit, bcryptjs<br>*   **Authentication:** JSON Web Tokens (JWT)<br>*   **Services:** Multer (image uploads), Nodemailer (email services)<br><br>---<br><br>## 🚀 Getting Started<br><br>Follow these steps to run the applications locally on your machine.<br><br>### Prerequisites<br>*   [Node.js](https://nodejs.org/) (v18.x or above recommended)<br>*   [MongoDB](https://www.mongodb.com/) (either running locally or a MongoDB Atlas connection string)<br><br>---<br><br>### 1. Backend Setup<br><br>1. Navigate to the backend directory:<br>   ```bash<br>   cd backend<br>   ```<br>2. Install dependencies:<br>   ```bash<br>   npm install<br>   ```<br>3. Set up your environment variables:<br>   * Copy the example configuration:<br>     ```bash<br>     cp .env.example .env<br>     ```<br>   * Open `.env` and fill in the required details (e.g. `MONGO_URI`, `JWT_SECRET`, and SMTP details).<br>4. Run the development server (runs with `nodemon` for auto-reload):<br>   ```bash<br>   npm run dev<br>   ```<br>   * The backend API server will start on [http://localhost:5000](http://localhost:5000) by default.<br><br>> [!NOTE]<br>> On the first startup, the database is seeded automatically with a default hierarchal category structure, mock clothing products (Tops, Bottoms, Shoes, etc.), and a default administrator account.<br><br>**Default Seeding Admin Credentials:**<br>*   **Email:** `admin@behencode.co`<br>*   **Password:** `BehencodeAdmin123!`<br><br>---<br><br>### 2. Frontend Setup<br><br>1. Navigate to the frontend directory:<br>   ```bash<br>   cd frontend<br>   ```<br>2. Install dependencies:<br>   ```bash<br>   npm install<br>   ```<br>3. Set up your environment variables:<br>   * Copy the example configuration:<br>     ```bash<br>     cp .env.example .env<br>     ```<br>   * Open `.env` and configure `NEXT_PUBLIC_API_URL` (points to the backend) and `NEXTAUTH_SECRET`.<br>4. Run the Next.js development server:<br>   ```bash<br>   npm run dev<br>   ```<br>   * The frontend application will be available at [http://localhost:3000](http://localhost:3000).<br><br>---<br><br>## 🔑 Key Features<br><br>1.  **Immersive User Experience:** Powered by modern animations (Framer Motion & GSAP), smooth scroll (Lenis), and modern typography.<br>2.  **Robust Category Hierarchy:** Categories are seeded with deep levels: Gender (`Men`, `Women`, `Child`) ➔ Subcategories (`Tops`, `Bottoms`, `Shoes`) ➔ Sub-subcategories (`T-Shirts`, `Jeans`, `Heels`).<br>3.  **Comprehensive Auth:** Secured with JWT tokens via custom middleware in the backend and integrated with NextAuth.js on the frontend.<br>4.  **Admin Portal:** Manage products, review purchases, handle categories, and monitor analytics.<br>5.  **Interactive Elements:** Swiper-based carousels, responsive mobile layouts, secure checkout flow, and custom product review systems.<br><br>---<br><br>## 🎨 Visual Identity<br><br>The brand identity uses a warm, cozy, and soft palette to represent comfort and authenticity:<br>*   🌸 **Blush:** `#f2d5d0`<br>*   🍂 **Rose:** `#d4856a`<br>*   🌾 **Dusty:** `#c4a49a`<br>*   🥛 **Cream:** `#faf6f2`<br>*   ✨ **Warm White:** `#fff9f6`<br>*   🪵 **Dark Brown:** `#2a1f1a`<br>
