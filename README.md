## 🧱 Architecture

```
Bahencode/
├── frontend/        # Next.js (UI + Animations)
├── backend/         # Node.js + Express API
├── behencode.html   # Static UI prototype
└── README.md
```

---

## ⚙️ Tech Stack

### 🖥️ Frontend

* Next.js (App Router + TypeScript)
* Tailwind CSS (modern styling)
* Framer Motion + GSAP (animations)
* Three.js (3D elements)
* NextAuth.js (authentication)
* React Hook Form + Zod (validation)

### ⚡ Backend

* Node.js + Express.js
* MongoDB (Mongoose)
* JWT Authentication
* bcryptjs (security)
* Multer (file uploads)
* Nodemailer (emails)

---

## 🚀 Getting Started

### 1️⃣ Backend Setup

```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

Runs on: `http://localhost:5000`

---

### 2️⃣ Frontend Setup

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

Runs on: `http://localhost:3000`
